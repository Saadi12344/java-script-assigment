Welcome to MySite

This website was built as a course assignment to demonstrate a simple, multi-page site with a Home, About Us, and Contact Us page — deployed live using GitHub Pages.

Introduction

MySite is a small demo project that brings together the core building blocks of front-end web development: semantic HTML for structure, CSS for styling, and a simple JavaScript-powered contact form. The goal of this site is to practice designing a clean, consistent layout that works across multiple pages while keeping navigation simple and the content easy to read.
