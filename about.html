Guidance & Instructions for Team Members

The following guidelines apply to anyone contributing to this project:

1. Follow the File Structure

Keep index.html, about.html, contact.html, and style.css in the same root folder so links between pages continue to work.

2. Match Naming Exactly

File and folder names are case-sensitive on GitHub Pages. Always use lowercase, e.g. style.css, not Style.css.

3. Keep the Navbar Consistent

When adding a new page, copy the existing header/nav block exactly so every page links to Home, About Us, and Contact Us the same way.

4. Reuse the Shared Stylesheet

Add new styles to style.css instead of writing inline styles, so the design stays consistent across all pages.

5. Test Before Committing

Open the page locally in a browser to confirm layout and links work before uploading changes to GitHub.

6. Write Clear Commit Messages

When uploading or editing files on GitHub, use a short, descriptive commit message (e.g. "Update About Us page content").
